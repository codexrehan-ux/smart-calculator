# Universal Calculator Pro

## Features
- **Basic Operations:** Addition, subtraction, multiplication, and division.
- **Scientific Functions:** Trigonometric functions, logarithms, and exponentiation.
- **Graphing Capabilities:** Plot functions and visualize data.
- **Unit Conversion:** Convert measurements between different units.
- **History Tracking:** Keep track of past calculations.
- **User-Friendly Interface:** Easy-to-navigate and intuitive design.

## Usage
1. **Basic Calculations:** Enter numbers and select operations from the main screen.
2. **Trigonometric Functions:** Use the scientific features for angles in degrees or radians.
3. **Graphing:** Input a function to graph it over a defined interval.
4. **Conversions:** Select the units you want to convert from and to.
5. **Access History:** View previous calculations from the history section.

## Technologies
- **Frontend:** React.js for building the user interface.
- **Backend:** Node.js with Express for server-side logic.
- **Database:** MongoDB for storing user history and settings.
- **Deployment:** Heroku for hosting.
